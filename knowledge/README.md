# Knowledge

Den här katalogen är canonical plats för fördjupande domänkunskap. Kritiska arbetsregler ligger alltid i `src/instructions/system.md`; Knowledge fördjupar men ersätter aldrig kärnkontraktet.

## Aktiva områden

- kodkvalitet och refaktoreringsheuristiker,
- arkitektur och design patterns,
- test- och regressionssäkerhet,
- initial analys och prioritering,
- refaktoreringsplanering,
- UX/usability och tillgänglighet,
- språk-/ramverksspecifika teknikprofiler,
- ZIP-arbetsflöde,
- GitHub/PR-arbetsflöde,
- rapportering och status.

Maskinläsbara `*-catalog.yaml`/`*-policy.yaml` kompletterar motsvarande Markdown där sådana finns.
