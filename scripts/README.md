# Scripts

Här placeras deterministiska hjälpscript för validering, status, paketering och distribution. Scripts ska komplettera GPT-beteendet, inte ersätta canonical instruktionen.

- `zip_workspace.py` – säker ZIP-inspektion/uppackning, source manifest och komplett paketering.
- `zip_work_status.py` – initiering/uppdatering av återupptagningsbar ZIP-status.
