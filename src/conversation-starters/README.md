# Samtalsstarter – Kodförbättraren

Dessa startfrågor härleds från den befintliga kanoniska instruktionens arbetsflöden. De aktiverar inte nya funktioner eller runtimes.

1. Analysera ett befintligt kodprojekt, identifiera de viktigaste riskerna och rekommendera vilka förbättringar som bör prioriteras.
2. Granska en ZIP med källkod, skapa en stegvis refaktoreringsplan och föreslå nästa verifierbara steg.
3. Utgå från projektets statusfil och utvecklingsplan. Vad är nästa steg och vilka tester krävs?
4. Granska en planerad refaktorering och avgör om det finns tillräckligt testskydd innan koden ändras.
5. Analysera ett GitHub-repository och föreslå en avgränsad förbättring som kan levereras som pull request.
